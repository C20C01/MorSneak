# MorSneak(撅电报)

0.1.0

## 内容

### 基本设定

* 以世界位置（维度+方块位置）为频率，区分不同的频道。
* 频道可同时持有不同的信号，但只对外输出最新的信号。

### 便携电台

* 使用便携电台可进入电台界面：
    * 频道选择模式：
        * 显示持有频道的列表。
        * 在点击后加入或退出该频道：
            * 加入频道后会自动监听该频道的信号。
            * 只能加入一个频道，加入新频道会退出旧频道。
            * 玩家背包内只能有一个加入频道的便携电台。
    * 频道删除模式：
        * 显示持有频道的列表。
        * 在点击后删除该频道。
    * 声音设置模式：
        * 显示服务器提供的电报声音的列表。
        * 在点击后切换电报声音（输出信号）。
    * 切换广播状态：
        * 默认是关闭的，开启后才能向频道发送信号。
* 添加频道：
    * 便携电台最多可持有16个频道。
    * 对磁石使用，可添加其所在位置的频道。
    * 在物品栏内，用磁石指针右键便携电台可添加磁石位置（磁石指针持有）所对应的频道。
    * 当添加已持有的频道时，便携电台会选中该频道。
* 接收信号：
    * 播放信号对应的声音。
    * 声音会根据发送者的位置进行偏移：
        * 在与发送者处在相同维度时，声音会偏向发送者的位置，最大偏移8个方块。
        * 在与发送者处在不同维度时，声音偏移将保持不变。
* 发送信号：
    * 当便携电台处在玩家的物品栏内时，按下`Shift`键（撅屁股）即可发送信号。

### 无线电方块

* 加入频道：
    * 对无线电方块使用磁石指针可使其加入磁石位置（磁石指针持有）所对应的频道。
    * 对无线电方块使用选有频道的便携电台可使其加入相同频道。
    * 当无线电方块被加载时，会自动加入其持有的频道。
* 退出频道：
    * 使无线电方块再次加入当前频道可使其退出该频道。
    * 当无线电方块被卸载时，会自动退出其持有的频道。

#### 无线电发射器

* 被红石信号激活时，向频道发送其所受到的红石信号强度。

#### 无线电接收器

* 接收频道的信号并输出红石信号强度。
